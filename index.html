01

Selected work

Systems first. A few things I have built, and what each one does.

  • 2026

    Multi-modal retrieval · TreeHacks 2026 · Two-track winner

    ShotSpot

    Search hours of video by describing a moment.

    Fuses what is on screen, what is said, and what is written into one index, so a plain-language description returns the exact frame instead of a timeline to scrub.

    Live demoGitHubDevpost

  • June 2026 - July 2026

    Agents for infrastructure · Amazon · Team Lead

    On-Call Auto-Triage Bot

    On-call tickets that arrive already investigated.

    An event-driven agent that reads an incoming on-call ticket, runs the playbook a human would have run, and posts the evidence back before anyone opens the page.

  • 2026

    GPU systems · Independent project

    GPU Job Scheduler

    Placement strategies for GPU jobs, benchmarked on real CUDA kernels.

    Compares placement strategies, including an LLM scheduling advisor against a baseline, using custom matrix-multiply kernels as the workload: 107.73 GFLOPS on a T4, with a 2.45x speedup from shared-memory tiling.

  • July 2024 - August 2024

    Computer vision · Carnegie Mellon AI Scholars

    Waste Classification CNN

    Automated waste sorting, from raw images to a tuned CNN.

    Built at Carnegie Mellon AI Scholars, reaching 95% validation accuracy. The original code stayed with the program, so the linked notebook rebuilds the pipeline on public data and measures what the augmentation was worth.

    GitHubOpen in ColabOriginal documentation
