GPU Job Scheduler

2026

Independent project

A GPU-aware scheduler that compares placement strategies for GPU workloads, benchmarked against real CUDA kernels rather than simulated load.

  • Built a scheduler that compares placement strategies for GPU workloads, including an LLM-based scheduling advisor evaluated against a baseline placement algorithm.
  • Wrote custom CUDA kernels — naive and shared-memory tiled matrix multiplication — as the real workload the scheduler places and times, verifying output correctness before benchmarking.
  • Benchmarked on a T4 GPU via Modal, reaching 107.73 GFLOPS with a 2.45x speedup from shared-memory tiling over the naive implementation.
  • Python
  • CUDA
  • Modal
  • T4 GPU
