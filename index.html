01

Selected work

Systems first. For each one: what it does, and how it is built if you want to look closer.

  • 2026

    Multi-modal retrieval · TreeHacks 2026 · Two-track winner

    ShotSpot

    Search hours of video by describing a moment.

    Fuses what is on screen, what is said, and what is written into one index, so a plain-language description returns the exact frame instead of a timeline to scrub.

    How it works+
    • ·Designed a multi-modal retrieval pipeline using CLIP (512-dimensional embeddings), Whisper, and OCR, fused with weighted cosine similarity.
    • ·Built distributed processing on FastAPI, MongoDB Atlas Vector Search, and Modal GPUs, scaling to 50+ concurrent video jobs via async task queues.
    • ·Cut dataset generation from two weeks to fifteen minutes and lowered false positives by 30-40%.

    CLIP · Whisper · OCR · FastAPI · MongoDB Vector Search · Modal

    Live demoGitHubDevpost

  • June 2026 - July 2026

    Agents for infrastructure · Amazon · Team Lead

    On-Call Auto-Triage Bot

    On-call tickets that arrive already investigated.

    An event-driven agent that reads an incoming on-call ticket, runs the playbook a human would have run, and posts the evidence back before anyone opens the page.

    How it works+
    • ·Built an event-driven pipeline from ticketing through EventBridge and Lambda into an agentic workflow, cutting context-gathering from 15-30 minutes to near-zero across 50+ tickets per week.
    • ·Architected confidence-scored intent classification with dynamic routing to specialized investigation skills, pulling evidence from CloudWatch and alarm history.
    • ·Implemented a closed-loop feedback mechanism where on-call reactions feed an offline evaluation pipeline for continuous improvement.

    AWS Lambda · EventBridge · CloudWatch · Python · Agentic workflows

  • 2026

    GPU systems · Independent project

    GPU Job Scheduler

    Placement strategies for GPU jobs, benchmarked on real CUDA kernels.

    Compares placement strategies, including an LLM scheduling advisor against a baseline, using custom matrix-multiply kernels as the workload: 107.73 GFLOPS on a T4, with a 2.45x speedup from shared-memory tiling.

    How it works+
    • ·Built a scheduler that compares placement strategies for GPU workloads, including an LLM-based scheduling advisor evaluated against a baseline placement algorithm.
    • ·Wrote custom CUDA kernels, naive and shared-memory tiled matrix multiplication, as the real workload the scheduler places and times, verifying output correctness before benchmarking.
    • ·Benchmarked on a T4 GPU via Modal, reaching 107.73 GFLOPS with a 2.45x speedup from shared-memory tiling over the naive implementation.

    Python · CUDA · Modal · T4 GPU

  • July 2024 - August 2024

    Computer vision · Carnegie Mellon AI Scholars

    Waste Classification CNN

    Automated waste sorting, from raw images to a tuned CNN.

    Built at Carnegie Mellon AI Scholars, reaching 95% validation accuracy. The original code stayed with the program, so the linked notebook rebuilds the pipeline on public data and measures what the augmentation was worth.

    How it works+
    • ·Built the full pipeline in TensorFlow and Keras, covering preprocessing, augmentation, and CNN model development.
    • ·Reached 95% validation accuracy while improving generalization and reducing overfitting.

    TensorFlow · Keras · CNNs · Python

    GitHubOpen in ColabOriginal documentation
